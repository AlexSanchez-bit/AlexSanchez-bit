# System Requirements

## Introduction

This document outlines the hardware and software requirements for setting up an IoT-based system using a Raspberry Pi and multiple SHT85 thermo-hygrometer probes. This system is designed to remotely monitor and record the tobacco curing process, offering a cost-effective alternative to imported equipment in Cuba's tobacco industry.

## Hardware Requirements

- **Raspberry Pi 3 Model B+**: This serves as the control element of the system. It is capable of connecting up to nine simultaneous sensing probes.
- **SHT85 Thermo-Hygrometer Probes**: These sensors are used for their high accuracy in monitoring temperature and humidity, comparable to commercial equipment.

## Software Requirements

- **IoT Platform**: The proposed platform is ThingsBoard, chosen for its versatility and performance in managing IoT data.
- **Cloud Connectivity**: The system registers all measured data in an IoT cloud platform, allowing for remote consultation from anywhere at any time.

## Summary

The IoT system for monitoring the tobacco curing process is a strategic initiative aimed at reducing costs and dependency on imported equipment in Cuba's tobacco industry. By utilizing a Raspberry Pi 3 Model B+ and SHT85 thermo-hygrometer probes, the system provides an accurate and efficient method for data collection and analysis, integrated with the ThingsBoard IoT platform for remote accessibility.

For more detailed information, please refer to the original article on the [Telemática Journal website](https://revistatelematica.cujae.edu.cu/index.php/tele/article/view/599).
