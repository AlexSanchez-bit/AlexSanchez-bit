# Security Configuration Guide

## Introduction

This guide provides an overview of security-related settings and configurations based on the exploration of the Red de Sobrevivientes web application and related studies. It aims to detail the navigation structure, interactive elements, and authentication mechanisms used within the application. The guide is intended for users seeking to understand the security configurations and settings of the application.

## Authentication Mechanisms

### Graphical Authentication API

The application utilizes a Passpoints-based graphical authentication system, which is designed to enhance security and usability compared to traditional alphanumeric passwords. This system is characterized by:

- **Security and Ease of Use**: Provides a secure method for user authentication while being user-friendly.
- **Adaptability**: The system is adaptable across various devices and screen resolutions, ensuring broad compatibility.

### Implementation Details

The implementation of the Passpoints system involves:

- **Discretization Methods**: A comprehensive analysis of discretization methods was conducted to ensure effective translation into programming code.
- **Device Compatibility**: Research was conducted to adapt the system to different screen resolutions and image sizes.

## Access Restrictions and Limitations

Certain navigation links within the application do not update the URL hash, which can lead to confusion when accessing specific content. For example:

- **Nuestros Aliados and Comparte tu Historia**: These sections change content without updating the URL hash.
- **Blog Page**: May display a message indicating "No hay nada que mostrar" when content is unavailable.
