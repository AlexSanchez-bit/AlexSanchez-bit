## Red Sobrevivientes Website

The Red Sobrevivientes website offers a variety of interactive features and content aimed at supporting survivors and providing information. Below are detailed steps and features of the website:

### Key Features

- **Testimony Submission Form**: Allows users to submit their stories with fields for name, involved person, gender, age, and location.
- **Blog Page**: Includes a donation section and chat feature, though it may display a message indicating no content is available.
- **Interactive Crime Statistics Map**: Provides a map of Colombian crime statistics with interactive elements.
- **Donation Page**: Offers multiple payment options, including PayPal and credit/debit cards.

### Interactive Elements

- **Modal Interactions**: Users can share their testimonies through modals triggered by specific buttons on the homepage.
- **Navigation Links**: Facilitate movement between sections such as 'Nuestros Aliados', 'Comparte tu historia', and 'Estadísticas y mapa'.

### Documentation Steps

1. **Initialize Documentation**: Begin by setting up `todo.md` and `results.json` with homepage information.
2. **Explore and Document Pages**: Navigate through pages like 'Sobre nosotros', 'Blog', and 'Estadísticas y mapa', updating documentation files with structured information.
3. **Compile Inventory**: Create a comprehensive JSON inventory of the website's features and interactions.

For more details, visit the [Red Sobrevivientes Website](https://red-sobrevivientes-web.netlify.app).

## Passpoints-Based Graphical Authentication API

The development of a Passpoints-based graphical authentication API addresses the limitations of traditional alphanumeric passwords. This system enhances security and usability through graphical authentication.

### Development Process

- **Functionality and Security Analysis**: The API was developed after an exhaustive study of the Passpoints system, focusing on its security and adaptability.
- **Implementation**: Involved selecting effective discretization methods and adapting the system to various screen resolutions and image sizes.

### Key Benefits

- **Enhanced Security**: Provides a more secure alternative to alphanumeric passwords.
- **Device Adaptability**: The system is designed to work across different devices and screen sizes.
