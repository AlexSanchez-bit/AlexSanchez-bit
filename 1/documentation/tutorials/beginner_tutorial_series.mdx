## Introduction

This tutorial series guides users through the process of navigating the Red de Sobrevivientes Colombia web application. It includes detailed steps for documenting content from specific pages, updating records, and marking tasks as complete. The tutorial focuses on hands-on learning, providing practical examples and exercises.

## Navigation and Documentation Process

The process involves systematically exploring various sections of the website, extracting information, and updating documentation files. Key actions include:

- Reading and updating `results.json` with page details.
- Marking tasks as complete in `todo.md`.
- Navigating through different sections using the main navigation menu.
- Extracting structured information from pages and modals.

## Exploration Steps

Below are the detailed steps for exploring and documenting the website:

1. **Initialize Documentation Files**: Start by initializing `todo.md` and `results.json` with the homepage information.
2. **Explore 'Sobre Nosotros'**: Click the 'Sobre nosotros' link and document its content.
3. **Document 'Nuestros Aliados'**: Extract information about the 'Nuestros Aliados' page.
4. **Navigate to 'Comparte tu historia'**: Explore and document the 'Comparte tu historia' page.
5. **Explore the 'Blog' Section**: Navigate to the 'Blog' page and extract its details.
6. **Document 'Estadísticas y mapa'**: Explore the map and statistics page for its features.
7. **Explore Donation Options**: Document the 'Haz una donación' page, focusing on donation mechanisms.

## Key Pages and Features

The website features several key pages, each with unique content and interactive elements:

- **Home Page**: Introduction to the organization, call to action buttons, and sections for allies and blog entries.
- **Sobre Nosotros**: Provides detailed information about the organization.
- **Nuestros Aliados**: Lists the organization's allies.
- **Comparte tu historia**: A page for sharing personal stories.
- **Blog**: Displays blog entries, though it may show "No hay nada que mostrar" if content is unavailable.
- **Estadísticas y mapa**: Features an interactive map with crime statistics.
- **Haz una donación**: Offers various donation options and payment methods.
