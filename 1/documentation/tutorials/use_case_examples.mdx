## Key Features and Interactive Elements

### Testimony Submission

- **Form Fields**: Nombre, Persona involucrada, Género, Su Género, Edad, Detalles (Cuenta tu historia..), Ubicación
- **Action Buttons**: Cancelar, Enviar testimonio

### Blog Page

- **Features**: Displays message 'No hay nada que mostrar', Donation section, Contact info, Chat feature
- **Interactive Elements**: Navigation links, Donation buttons, Chat feature

### Statistics and Map

- **Features**: Main description 'Mapa colombiano de los delitos...', Interactive map tiles
- **Interactive Elements**: Navigation links, Buttons 'Explora', 'Descubre'

### Donation Page

- **Features**: Donation options and amounts, Payment provider integration (PayPal/Debit/Credit Card)
- **Interactive Elements**: Navigation links, Donation amount buttons, Payment method buttons

## Summary

This document outlines the steps and interactions necessary to navigate the Red Sobrevivientes web application effectively. By following the outlined steps, users can update documentation, explore modals, and compile comprehensive inventories. The application features various interactive elements across different pages, including testimony submission forms, a blog page, an interactive crime statistics map, and a donation page with multiple payment methods.

For more detailed exploration, visit the [Red Sobrevivientes Web Application](https://red-sobrevivientes-web.netlify.app).
