# Intermediate Workflows

## Introduction

This tutorial provides a comprehensive guide to building more complex workflows by documenting and updating structured information from various pages of the Red Sobrevivientes website. The steps outlined will help you navigate through different sections, extract relevant data, and update necessary files to maintain a comprehensive inventory of the website's features and interactive elements.

## Workflow Steps

### Initial Setup

1. **Initialize Documentation Files**
   - Begin by initializing `todo.md` and `results.json` with the documented information for the homepage.
   - URL: [Homepage](https://red-sobrevivientes-web.netlify.app/#/)

### Navigating and Documenting Pages

2. **Explore 'Sobre Nosotros' Page**
   - Click the 'Sobre nosotros' link and scroll down to document its features.
   - Update `results.json` with the extracted information.
   - URL: [Sobre Nosotros](https://red-sobrevivientes-web.netlify.app/#/us)

3. **Document 'Nuestros Aliados' Page**
   - Click the 'Nuestros Aliados' link and extract structured information about the page.
   - Update `results.json` and mark the task as complete in `todo.md`.
   - URL: [Nuestros Aliados](https://red-sobrevivientes-web.netlify.app/#/)

4. **Explore 'Comparte tu Historia' Page**
   - Click the 'Comparte tu historia' link, document the page title, URL, and form fields.
   - Update `results.json` and mark the task as complete.
   - URL: [Comparte tu Historia](https://red-sobrevivientes-web.netlify.app/#/)

5. **Navigate to 'Blog' Section**
   - Click the 'Blog' link, scroll to reveal content, and document the page features.
   - Update `results.json` and mark the task as complete.
   - URL: [Blog](https://red-sobrevivientes-web.netlify.app/#/blog)

### Advanced Documentation

6. **Document 'Estadísticas y Mapa' Page**
   - Extract structured information about the map and interactive buttons.
   - Update `results.json` and mark the task as complete.
   - URL: [Estadísticas y Mapa](https://red-sobrevivientes-web.netlify.app/#/map)

7. **Explore 'Haz una Donación' Page**
   - Document donation options and interactive elements.
   - Update `results.json` and mark the task as complete.
   - URL: [Haz una Donación](https://red-sobrevivientes-web.netlify.app/#/donate)

8. **Modal Interactions**
   - Click 'Sí, soy Sobreviviente.' to open the 'Comparte tu testimonio' modal.
   - Document the modal's features and update `results.json`.
   - URL: [Comparte tu Testimonio](https://red-sobrevivientes-web.netlify.app/#/)

### Finalizing Documentation

9. **Compile Comprehensive Inventory**
   - Compile the comprehensive inventory of the web application into a detailed JSON structure.
   - Mark the final task as complete in `todo.md`.

10. **Prepare Final Output**
    - Read the content of `results.json` to prepare the final output for the user.

## Summary

This tutorial provided a step-by-step guide to documenting and updating structured information from various sections of the Red Sobrevivientes website. By following these steps, you can maintain an up-to-date inventory of the website's features and interactive elements, ensuring comprehensive documentation and effective workflow management.

For more detailed exploration, visit the [Red Sobrevivientes Website](https://red-sobrevivientes-web.netlify.app).
