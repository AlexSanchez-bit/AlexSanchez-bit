# Advanced Use Cases

## Introduction

This documentation page explores advanced use cases and complex scenarios related to the Red Sobrevivientes website. The content is derived from a systematic process of exploring and documenting various sections of the website, including the 'Blog', 'Estadísticas y mapa', 'Haz una donación', and 'Comparte tu testimonio' sections. This page provides insights into the features, interactive elements, and structured information extracted from these sections.

## Exploring the Website Sections

### Blog Section

- **URL**: [Blog Page](https://red-sobrevivientes-web.netlify.app/#/blog)
- **Page Type**: Blog Listing
- **Key Features**:
  - Displays message: "No hay nada que mostrar" (No content available)
  - Includes a donation section
  - Provides contact information and a chat feature
- **Interactive Elements**:
  - Navigation links
  - Donation buttons
  - Chat feature

### Estadísticas y Mapa

- **URL**: [Estadísticas y Mapa](https://red-sobrevivientes-web.netlify.app/#/map)
- **Page Type**: Map/Statistics
- **Key Features**:
  - Main description: "Mapa colombiano de los delitos..."
  - Interactive map tiles
- **Interactive Elements**:
  - Navigation links
  - Two main buttons: "Explora", "Descubre"

### Haz una Donación

- **URL**: [Donation Page](https://red-sobrevivientes-web.netlify.app/#/donate)
- **Page Type**: Donation
- **Key Features**:
  - Donation options and amounts
  - Payment provider integration (PayPal/Debit/Credit Card)
- **Interactive Elements**:
  - Navigation links
  - Donation amount buttons
  - Payment method buttons

### Comparte tu Testimonio

- **URL**: [Modal Context](https://red-sobrevivientes-web.netlify.app/#/)
- **Page Type**: Modal/In-page Form (Secondary interaction)
- **Key Features**:
  - Opened by clicking 'Sí, soy Sobreviviente.' on the homepage.
  - Initial options: "Soy Sobreviviente" and "No soy sobreviviente, pero conozco uno."
- **Interactive Elements**:
  - Form fields (same as 'Comparte tu historia' page)
  - Action buttons: Cancelar, Enviar testimonio
  - Close button

## Secondary Interactions

- **'Sí, soy Sobreviviente.' Button**: Opens the 'Comparte tu testimonio' modal/in-page form.
- **'No, pero quiero información.' Button**: Navigates to the 'Sobre nosotros' page.

## Access Restrictions and Limitations

- The Blog page displays "No hay nada que mostrar."
- Navigation links for 'Nuestros Aliados' and 'Comparte tu historia' do not update the URL hash, remaining on the base URL (/#/).
