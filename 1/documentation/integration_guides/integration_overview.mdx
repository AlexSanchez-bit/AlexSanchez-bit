# Integration Overview

This document provides an overview of the available integrations and capabilities for the Red Sobrevivientes platform. The platform offers various interactive features and resources aimed at supporting survivors in Colombia. This includes testimony submission forms, donation options, an interactive crime statistics map, and a blog page with additional functionalities.

## Key Features and Integrations

### Testimony Submission

The platform provides a dedicated section for survivors to share their stories. This feature is accessible through a modal that opens when users click "Sí, soy Sobreviviente" on the homepage.

- **Form Fields**:
  - Nombre
  - Persona involucrada
  - Género
  - Su Género
  - Edad
  - Detalles (Cuenta tu historia..)
  - Ubicación
- **Action Buttons**:
  - Cancelar
  - Enviar testimonio

### Donation Options

The donation page offers multiple payment methods, integrating with providers such as PayPal, Debit, and Credit Cards. This allows users to support the platform financially with ease.

- **Interactive Elements**:
  - Donation amount buttons
  - Payment method buttons

### Interactive Crime Statistics Map

The platform includes an interactive map that displays crime statistics across Colombia. This feature is designed to provide users with insights into regional crime data.

- **Main Description**: "Mapa colombiano de los delitos..."
- **Interactive Elements**:
  - Navigation links
  - Buttons: "Explora", "Descubre"

### Blog and Additional Features

The blog section, although currently displaying "No hay nada que mostrar", is equipped with a donation section and a chat feature for user interaction.

- **Interactive Elements**:
  - Navigation links
  - Donation buttons
  - Chat feature

## Navigation and Access

The platform's navigation includes several key pages:

- **Home**: [Red Sobrevivientes Home](https://red-sobrevivientes-web.netlify.app/#/)

- **Blog**: [Blog Page](https://red-sobrevivientes-web.netlify.app/#/blog)
- **Estadísticas y mapa**: [Statistics and Map](https://red-sobrevivientes-web.netlify.app/#/map)

## Summary

The Red Sobrevivientes platform integrates various features to support survivors, including testimony submission, donation options, and an interactive crime statistics map. While the blog currently lacks content, it remains a potential space for future updates and user engagement. The platform's navigation and interactive elements are designed to enhance user experience and accessibility.

For more detailed exploration of the platform's features, visit [Red Sobrevivientes](https://red-sobrevivientes-web.netlify.app).
