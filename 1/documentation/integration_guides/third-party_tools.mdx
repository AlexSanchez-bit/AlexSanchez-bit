# Third-Party Tools Integration Guide

## Introduction

This guide provides an overview of popular tool integrations and plugins available on the Red Sobrevivientes website. The site offers various interactive features, including testimony submission forms, donation options, and an interactive crime statistics map, all designed to support survivors in Colombia.

## Key Features and Interactive Elements

### Testimony Submission

- **Form Fields**: The testimony submission form includes fields such as Nombre, Persona involucrada, Género, Su Género, Edad, Detalles (Cuenta tu historia..), and Ubicación.
- **Action Buttons**: Users can interact with the form using the 'Cancelar' and 'Enviar testimonio' buttons.

### Blog

- **Page Type**: Blog Listing
- **Key Features**: The blog page displays a message indicating 'No hay nada que mostrar' when no content is available. It includes a donation section and contact information, along with a chat feature.
- **Interactive Elements**: Users can navigate using links and interact with donation buttons and the chat feature.

### Crime Statistics Map

- **Page Type**: Map/Statistics
- **Key Features**: The map provides a Colombian crime statistics overview with interactive tiles.
- **Interactive Elements**: Navigation links and buttons labeled 'Explora' and 'Descubre' allow users to interact with the map.

### Donation Page

- **Page Type**: Donation
- **Key Features**: The page offers various donation options and amounts, integrating payment providers like PayPal, Debit, and Credit Card.
- **Interactive Elements**: Users can select donation amounts and payment methods through dedicated buttons.

### Sharing Survivor Stories

- **Page Type**: Modal/In-page Form
- **Key Features**: This feature is accessible by clicking 'Sí, soy Sobreviviente.' on the homepage. It provides options for survivors and those who know a survivor.
- **Interactive Elements**: The modal includes form fields similar to the 'Comparte tu historia' page and action buttons for submitting or canceling the testimony.

## Navigation and Access

- **Navigation Links**: The site includes links to various sections, such as 'Sobre nosotros' and 'Nuestros Aliados', although some links do not update the URL hash.
- **Access Restrictions**: The blog page may display 'No hay nada que mostrar', indicating no available content.

## Summary

The Red Sobrevivientes website integrates several third-party tools and interactive elements to facilitate user engagement and support for survivors. From testimony submissions to interactive maps and donation options, the site provides a comprehensive platform for advocacy and support. For more detailed exploration of these features, please visit the [Red Sobrevivientes website](https://red-sobrevivientes-web.netlify.app).
