# Feature Comparisons

## Introduction

This documentation provides a comparison of various features available on the Red de Sobrevivientes web application. The platform is designed to support survivors in Colombia by offering resources such as testimony submission forms, donation options, and an interactive crime statistics map. This document outlines the key features and interactive elements of the website's main pages.

## Key Features and Interactive Elements

### 1. Testimony Submission Form

- **Page Type**: Form/Testimony Submission
- **Key Features**:
  - Allows users to submit their testimonies.
  - Includes fields for "Nombre," "Persona involucrada," "Género," "Su Género," "Edad," "Detalles," and "Ubicación."
- **Interactive Elements**:
  - Action buttons: "Cancelar," "Enviar testimonio."

### 2. Blog

- **Page Type**: Blog Listing
- **Key Features**:
  - Displays a message when no content is available: "No hay nada que mostrar."
  - Includes a donation section and contact information.
- **Interactive Elements**:
  - Navigation links, donation buttons, and a chat feature.

### 3. Estadísticas y Mapa

- **Page Type**: Map/Statistics
- **Key Features**:
  - Features an interactive map titled "Mapa colombiano de los delitos."
- **Interactive Elements**:
  - Navigation links and two main buttons: "Explora," "Descubre."

### 4. Donation Page

- **Page Type**: Donation
- **Key Features**:
  - Offers various donation options and amounts.
  - Integrates with payment providers such as PayPal, Debit, and Credit Card.
- **Interactive Elements**:
  - Navigation links and donation amount buttons.

### 5. Survivor Story Sharing Modal

- **Page Type**: Modal/In-page Form
- **Key Features**:
  - Opens when clicking "Sí, soy Sobreviviente." on the homepage.
  - Initial options include "Soy Sobreviviente" and "No soy sobreviviente, pero conozco uno."
- **Interactive Elements**:
  - Form fields similar to the "Comparte tu historia" page.
  - Action buttons: "Cancelar," "Enviar testimonio," and a close button.

## Summary

The Red de Sobrevivientes web application provides a comprehensive set of features designed to support survivors in Colombia. Key functionalities include testimony submission, a blog with donation options, an interactive crime statistics map, and a dedicated donation page with multiple payment methods. Each page is equipped with interactive elements to enhance user engagement and facilitate navigation.

For more information, visit the [Red de Sobrevivientes website](https://red-sobrevivientes-web.netlify.app).
