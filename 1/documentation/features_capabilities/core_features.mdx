# Core Features of Red de Sobrevivientes Web Application

## Introduction

The Red de Sobrevivientes web application serves as a platform for survivors in Colombia to share their testimonies, access resources, and connect with allies. This documentation provides an overview of the core features and functionalities available on the website, highlighting the interactive elements and key components that facilitate user engagement and support.

## Key Features

### Testimony Submission

The platform offers a dedicated form for survivors to submit their testimonies. This feature is accessible via a modal that opens when users click "Sí, soy Sobreviviente" on the homepage. The form includes fields for:

- Nombre
- Persona involucrada
- Género
- Su Género
- Edad
- Detalles (Cuenta tu historia..)
- Ubicación

Action buttons available are "Cancelar" and "Enviar testimonio."

### Blog

The blog section provides an area for updates and articles, though it may sometimes display a message indicating no content is available. Key features include:

- Donation section
- Contact information
- Chat feature

### Interactive Crime Statistics Map

The "Estadísticas y mapa" page features an interactive map that provides insights into crime statistics in Colombia. Users can explore the map using the "Explora" and "Descubre" buttons.

### Donation Page

The donation page allows users to contribute to the organization through various methods, including:

- PayPal
- Debit or Credit Card

Interactive elements include donation amount buttons and payment method options.

### About Us

The "Sobre nosotros" page provides information about the organization's mission, vision, and commitment to Colombia. It outlines six work axes, such as direct legal attention and awareness-raising efforts. Contact information is also available.

### Allies

The "Nuestros Aliados" section lists the organization's allies and provides additional donation options and contact details.

## Interactive Elements

The website features several interactive elements designed to enhance user experience, including:

- Main navigation menu
- Chat input fields
- Survivor status confirmation buttons
- Social media buttons (Instagram, X)

## Summary

The Red de Sobrevivientes web application is a comprehensive platform that supports survivors in Colombia through testimony sharing, information dissemination, and community engagement. Its core features, including testimony submission, an interactive map, and donation options, are designed to empower users and facilitate support for the organization's mission.

For more information, visit the [Red de Sobrevivientes website](https://red-sobrevivientes-web.netlify.app).
