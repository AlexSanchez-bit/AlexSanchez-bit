# Limitations

## Introduction

This document outlines the known limitations and constraints of the Red de Sobrevivientes web application. The application provides various resources, including testimony submission forms, donation options, and an interactive map of crimes. However, there are certain limitations that users may encounter while navigating the site.

## Navigation Limitations

- **URL Hash Updates**: Some navigation links, such as 'Nuestros Aliados' and 'Comparte tu historia', do not update the URL hash. This means that while the content on the page may change, the URL remains the same, which can lead to confusion about the current page state. The base URL remains as `https://red-sobrevivientes-web.netlify.app/#/`.

- **Blog Page Content**: The Blog page often displays a message stating "No hay nada que mostrar" (No content available), indicating that there may be issues with content availability or loading.

## Interactive Elements

- **Testimony Submission Form**: The form includes fields such as Nombre, Persona involucrada, Género, Su Género, Edad, Detalles (Cuenta tu historia..), and Ubicación. Users can interact with action buttons like 'Cancelar' and 'Enviar testimonio'. However, the form's functionality may be limited if certain fields are not filled correctly.

- **Modal and In-Page Forms**: Clicking the 'Sí, soy Sobreviviente.' button on the homepage opens a modal or in-page form for sharing survivor stories. This feature is crucial for user interaction but may have limitations if the form fields are not properly validated.

## Access Restrictions

- **Content Display Issues**: On certain pages, such as the Blog, users may encounter messages indicating that there is no content to display. This can affect the user experience and limit the information available to users.

## Summary

The Red de Sobrevivientes web application offers valuable resources and interactive elements for users, including testimony submission forms and donation options. However, users may experience limitations related to URL hash updates, content availability on the Blog page, and potential issues with form validation. These limitations are important to consider for improving user experience and functionality.

For more information, visit the [Red de Sobrevivientes web application](https://red-sobrevivientes-web.netlify.app).
