# Collaboration Tools

## Introduction

This guide provides an overview of the collaboration and sharing features available on the Red Sobrevivientes website. This platform offers a variety of interactive elements designed to facilitate communication, support, and resource sharing among users, particularly focusing on survivors in Colombia.

## Features & Capabilities

### Testimony Submission

The website includes a testimony submission form that allows users to share their stories. This feature is accessible through a modal that opens when users click "Sí, soy Sobreviviente" on the homepage. The form includes fields for:

- Nombre
- Persona involucrada
- Género
- Su Género
- Edad
- Detalles (Cuenta tu historia..)
- Ubicación

Action buttons available are "Cancelar" and "Enviar testimonio".

### Blog and Chat

The blog section of the website provides a platform for sharing updates and stories. It includes:

- A message display: "No hay nada que mostrar" (No content available)
- A donation section
- Contact information
- A chat feature for real-time communication

### Interactive Map

The "Estadísticas y mapa" page features an interactive map that provides crime statistics in Colombia. Key interactive elements include:

- Navigation links
- Two main buttons: "Explora" and "Descubre"

### Donation Options

The "Haz una donación" page offers various donation options, integrated with payment providers like PayPal, Debit, and Credit Card. Users can select different donation amounts and methods through interactive buttons.

### Allies and Support

The "Nuestros Aliados" page lists allies and provides support information. It includes:

- Ally listing (e.g., CRIN - home.crin.org)
- Donation options (Donate, Pay Later, Debit or Credit Card)
- Contact details (WhatsApp: +57 302 5834033, Email: marcos@sobrevivientes-clerical.org)

### Contact and Social Media

The "Sobre nosotros" page outlines the organization's mission and contact information, including:

- Vision statement and commitment to Colombia
- Contact information (Email: redsobrevivientes@protonmail.com, Phone: +57 302 583 4033)
- Social media buttons (Instagram, X)

## Summary

The Red Sobrevivientes website is a comprehensive platform offering various tools for collaboration and sharing among survivors and allies. Key features include testimony submission, an interactive map, donation options, and a blog with chat capabilities. These elements are designed to facilitate support and resource sharing within the community.

For more information, visit the Red Sobrevivientes website: [red-sobrevivientes-web.netlify.app](https://red-sobrevivientes-web.netlify.app)
