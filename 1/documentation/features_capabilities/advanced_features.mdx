# Advanced Features

## Introduction

This documentation page provides an overview of advanced functionalities available for power users. The features discussed here are derived from the exploration of the Red de Sobrevivientes web application and the development of a Passpoints-based graphical authentication API. These advanced features enhance user interaction and security, offering a comprehensive experience across different platforms.

## Red de Sobrevivientes Web Application

The Red de Sobrevivientes web application offers a variety of interactive features and pages designed to engage users and provide valuable information. Below is a detailed exploration of its navigation structure and key functionalities.

### Navigation Structure

The application consists of five unique pages, each offering distinct content and interactive elements:

- **Home Page**: Provides an introduction to the organization with calls to action for survivors and interested parties. It includes sections for allies, latest blog entries, and donation options.
  - URL: [Home](https://red-sobrevivientes-web.netlify.app/#/)

- **Sobre Nosotros**: Offers detailed information about the organization.
  - URL: [Sobre Nosotros](https://red-sobrevivientes-web.netlify.app/#/us)

- **Blog**: Displays blog entries, although it may sometimes show no content.
  - URL: [Blog](https://red-sobrevivientes-web.netlify.app/#/blog)

- **Estadísticas y Mapa**: Features an interactive map displaying crime statistics.
  - URL: [Estadísticas y Mapa](https://red-sobrevivientes-web.netlify.app/#/map)

- **Haz una Donación**: Provides options for donations with multiple payment methods.
  - URL: [Haz una Donación](https://red-sobrevivientes-web.netlify.app/#/donate)

### Key Features

- **Interactive Elements**: The application includes various interactive elements such as navigation links, buttons for exploring content, and forms for user input.
- **Testimony Submission**: Users can submit their stories through a form available on the homepage.
- **Donation Options**: The donation page supports multiple payment methods, including PayPal and credit cards.

## Passpoints-Based Graphical Authentication API

The Passpoints-based graphical authentication API is a novel approach to enhancing security by replacing traditional alphanumeric passwords with graphical authentication. This system is designed to be secure and user-friendly, adaptable to various devices and screen resolutions.

### Development and Implementation

- **Security and Functionality**: The API addresses the weaknesses of alphanumeric passwords by offering a more secure and intuitive authentication method.
- **Adaptability**: The system is adaptable to different screen sizes and resolutions, making it suitable for a wide range of devices.
- **Research and Analysis**: Extensive research was conducted to select effective discretization methods for translating the system into programming code.

### Publications and Resources

- **Publication**: The development of this API is documented in the article "Development of a Passpoints-Based Graphical Authentication API" by Alex Sánchez Saez et al., published in *Telemática*.
- **Download**: The article is available for download in PDF format [here](https://revistatelematica.cujae.edu.cu/index.php/tele/article/view/970/523).
