# Feature Overview

This document provides a comprehensive overview of the features available in the Red de Sobrevivientes web application. The application is designed to support survivors in Colombia by offering various resources, interactive elements, and opportunities for engagement.

## Navigation Structure

The Red de Sobrevivientes web application consists of several key pages, each serving a distinct purpose:

- **Home Page**: [Red de Sobrevivientes Colombia](https://red-sobrevivientes-web.netlify.app/#/)
  - Introduction to the organization
  - Call to action for survivors and interested parties
  - Latest blog entries
  - Donation section

- **Sobre Nosotros**: [About Us](https://red-sobrevivientes-web.netlify.app/#/us)
  - Vision statement
  - Commitment to Colombia
  - Six Work Axes (e.g., legal assistance, awareness)
  - Contact information

- **Blog**: [Blog](https://red-sobrevivientes-web.netlify.app/#/blog)
  - Displays a message when no content is available
  - Donation section
  - Contact information and chat feature

- **Estadísticas y Mapa**: [Statistics and Map](https://red-sobrevivientes-web.netlify.app/#/map)
  - Interactive map of crimes in Colombia
  - Buttons for exploration and discovery

- **Haz una Donación**: [Make a Donation](https://red-sobrevivientes-web.netlify.app/#/donate)
  - Donation options and amounts
  - Payment provider integration (PayPal, Debit/Credit Card)

- **Comparte tu Historia**: Testimony Submission
  - Form for survivors to share their stories
  - Interactive elements such as form fields and action buttons

## Key Features

### Testimony Submission

The application provides a platform for survivors to share their testimonies through a dedicated form. Key features include:

- Form fields: Name, Involved Person, Gender, Age, Details, Location
- Action buttons: Cancel, Submit Testimony

### Blog and Communication

The blog page serves as a communication hub, offering:

- Donation section
- Contact information
- Chat feature for real-time interaction

### Interactive Map

The "Estadísticas y Mapa" page features an interactive map that allows users to explore crime statistics in Colombia. Users can interact with the map using:

- Navigation links
- Buttons: "Explora" and "Descubre"

### Donation Options

The donation page provides multiple ways to support the organization:

- Donation amount buttons
- Payment method buttons for PayPal, Debit, and Credit Cards

## Interactive Elements

Throughout the application, users can engage with various interactive elements, including:

- Main navigation menu
- Survivor status confirmation buttons
- Chat input field
- Social media buttons

## Summary

The Red de Sobrevivientes web application is a comprehensive platform designed to support survivors in Colombia. It offers a range of features, including testimony submission, interactive maps, donation options, and communication tools. Each page is equipped with interactive elements to enhance user engagement and provide necessary resources for survivors and allies.

For more detailed exploration of the application, visit the [Red de Sobrevivientes web application](https://red-sobrevivientes-web.netlify.app).
