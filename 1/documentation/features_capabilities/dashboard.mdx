# Dashboard Guide

## Introduction

This guide provides an overview of using the main dashboard interface of the Red de Sobrevivientes Colombia web application. The dashboard is designed to facilitate navigation and interaction with various features and pages of the website. This documentation will guide you through the steps to effectively use the dashboard, highlighting key features and interactive elements.

## Navigation Structure

The Red de Sobrevivientes Colombia web application features a structured navigation hierarchy that allows users to access different sections of the site. Below is the navigation structure:

- **Home**: [Red de sobrevivientes Colombia](https://red-sobrevivientes-web.netlify.app/#/)
- **Sobre nosotros**: [About Us](https://red-sobrevivientes-web.netlify.app/#/us)
- **Nuestros Aliados**: Content changes without updating the URL hash.
- **Comparte tu historia**: Content changes without updating the URL hash.
- **Blog**: [Blog](https://red-sobrevivientes-web.netlify.app/#/blog)
- **Estadísticas y mapa**: [Statistics and Map](https://red-sobrevivientes-web.netlify.app/#/map)
- **Haz una donación**: [Make a Donation](https://red-sobrevivientes-web.netlify.app/#/donate)

## Key Features

### Home Page

- **Introduction to the Organization**: Provides an overview of the organization's mission and activities.
- **Call to Action**: Buttons for survivors ("Sí, soy Sobreviviente") and interested parties ("No, pero quiero información").
- **Section for Allies**: Information about partners and allies.
- **Latest Blog Entries**: Displays recent blog posts.
- **Donation Section**: Encourages donations to support the organization.

### Interactive Elements

- **Main Navigation Menu**: Allows users to navigate between different sections of the site.
- **Buttons**:
  - "Sí, soy Sobreviviente" opens a form for survivors to share their stories.
  - "No, pero quiero información" navigates to the "Sobre nosotros" page.

## Page Exploration Steps

### General Steps

1. **Loading the SPA**: Wait for 3 seconds to allow the Single Page Application (SPA) to load its interactive elements.
2. **Documentation Updates**: Use `results.json` and `todo.md` to document page details and mark tasks as complete.

### Specific Page Actions

- **Nuestros Aliados**: Update `results.json` with page details and mark the task as complete.
- **Comparte tu historia**: Extract page title, URL, page type, key features, and form fields.
- **Blog**: Navigate to the Blog page and document its features, noting the message "No hay nada que mostrar".
- **Estadísticas y mapa**: Document the map description and interactive buttons.
- **Haz una donación**: Focus on donation mechanisms and interactive elements.

## Summary

The Red de Sobrevivientes Colombia web application provides a comprehensive dashboard interface that facilitates navigation through various sections of the site. Key features include interactive elements such as navigation links and action buttons, which enhance user engagement. The documentation process involves updating structured files (`results.json` and `todo.md`) to ensure all page details are captured accurately.

For more information, visit the [Red de Sobrevivientes Colombia website](https://red-sobrevivientes-web.netlify.app).
