# User Preferences

## Introduction

This guide provides an overview of individual user settings and preferences, focusing on available configurations and settings. It is part of the main product documentation and guides under the Configuration & Settings group.

## Language Settings

Users can set their preferred language for interacting with the Telemática Journal's online interface. The journal offers options in both English and Spanish. To change the language, users can select from the following options:

- [English](https://revistatelematica.cujae.edu.cu/index.php/tele/user/setLocale/en_US?source=%2Findex.php%2Ftele%2Findex)
- [Español (España)](https://revistatelematica.cujae.edu.cu/index.php/tele/user/setLocale/es_ES?source=%2Findex.php%2Ftele%2Findex)

## Submission Preferences

Users interested in submitting articles to the Telemática Journal can access submission guidelines and make submissions through the following link:

- [Make a Submission](https://revistatelematica.cujae.edu.cu/index.php/tele/about/submissions)

## Interactive Elements

On the Red Sobrevivientes website, users can interact with various elements designed to enhance user experience and engagement. These include:

- **Main Navigation Menu**: Allows users to navigate through different sections of the website.
- **Interactive Buttons**: Options like "Sí, soy Sobreviviente" open forms for survivors to share their stories.
- **Donation Links/Buttons**: Facilitate contributions to support the platform's mission.

## Summary

This documentation page outlines the user preferences available for the Telemática Journal and Red Sobrevivientes website. Users can configure language settings, make article submissions, and engage with interactive elements on the platforms. For further assistance, contact details are provided to support user inquiries and contributions.

For more information, visit the [Telemática Journal](https://revistatelematica.cujae.edu.cu/index.php/tele/index) and [Red Sobrevivientes](https://red-sobrevivientes-web.netlify.app) websites.
