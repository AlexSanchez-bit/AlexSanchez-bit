# Reporting Guide

## Introduction

This guide provides instructions on generating and customizing reports within the Red de Sobrevivientes web application. The process involves documenting, testing, and compiling a comprehensive inventory of the web application's interactive features and pages.

## Web Application Exploration

The exploration of the Red de Sobrevivientes web application involves navigating through various pages and documenting their features. The following steps outline the process:

### Navigation and Documentation

1. **Initialize Documentation**: Start by creating a comprehensive checklist in `todo.md` and wait for the SPA content to load.
2. **Explore Pages**: Navigate through the following pages:
   - [Home](https://red-sobrevivientes-web.netlify.app/)
   - [About Us](https://red-sobrevivientes-web.netlify.app/#/us)
   - [Blog](https://red-sobrevivientes-web.netlify.app/#/blog)
   - [Statistics and Map](https://red-sobrevivientes-web.netlify.app/#/map)

3. **Document Features**: Extract structured information from each page, focusing on interactive elements such as buttons and forms. Update the `results.json` file with this information.

### Interactive Feature Testing

1. **Form Testing**: Test the "Comparte tu historia" form by selecting user details, filling required fields, and submitting the form to verify its functionality.
2. **Map Interaction**: On the "Estadísticas y mapa" page, test interactive features by clicking buttons like 'Explora' and 'Descubre'.

### Compiling the Inventory

1. **Prepare JSON Output**: Compile the comprehensive inventory of the web application into a JSON structure.
2. **Finalize Documentation**: Mark tasks as complete in `todo.md` and prepare the final JSON output for the user.

## Summary

This guide outlines the process of generating and customizing reports by exploring and documenting the Red de Sobrevivientes web application. The steps include initializing documentation, navigating through pages, testing interactive features, and compiling a comprehensive inventory in JSON format. For more detailed exploration, visit the [Red de Sobrevivientes website](https://red-sobrevivientes-web.netlify.app).
