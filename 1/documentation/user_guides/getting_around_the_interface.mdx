# Getting Around the Interface

This guide provides step-by-step instructions for navigating the user interface of the Red de Sobrevivientes Colombia web application. By following these steps, users can effectively interact with various sections of the website, ensuring a smooth and efficient experience.

## Navigating the Main Menu

To access different sections of the website, users need to ensure the main navigation menu is visible and interactive. Here are the steps to achieve this:

1. **Scroll Up to Access the Menu**:
   - Scroll up approximately 0.7 to 1 page to bring the main navigation menu into view. This action makes the navigation links interactive.
   - Once the menu is visible, you can click on the desired link, such as the 'Blog' link.

2. **Refreshing the Page**:
   - If the navigation menu does not appear interactive, navigate to the base URL to refresh the page and re-index the navigation elements.
   - After refreshing, wait for a few seconds to allow the Single Page Application (SPA) to load fully.

## Exploring Specific Sections

### Blog Section

- **Accessing the Blog**:
  - Once the main navigation menu is visible, click on the 'Blog' link to navigate to the Blog section.
  - Scroll down 2.5 pages to reveal the content and interactive elements of the Blog page.

- **Documenting the Blog**:
  - Extract structured information about the Blog page, noting any messages such as 'No hay nada que mostrar'.

### Estadísticas y Mapa Section

- **Accessing the Estadísticas y Mapa**:
  - Click the 'Estadísticas y mapa' link from the main navigation menu.
  - Scroll down 2.5 pages to explore the content and document its features, including the map description and interactive buttons.

### Other Sections

- **Nuestros Aliados**:
  - Click the 'Nuestros Aliados' link and scroll down to document the page's content and features.

- **Comparte tu Historia**:
  - Navigate to the 'Comparte tu historia' page and extract details such as page title, URL, and form fields.

- **Donation Page**:
  - Access the 'Haz una donación' page to explore donation options and interactive elements like payment method buttons.

## Summary

Navigating the Red de Sobrevivientes Colombia web application involves making the main navigation menu visible by scrolling up and refreshing the page if necessary. Users can explore various sections such as the Blog, Estadísticas y Mapa, and others by following the outlined steps. Each section provides specific content and interactive elements that can be documented for further use.

For more information, visit the [Red de Sobrevivientes Colombia website](https://red-sobrevivientes-web.netlify.app).
