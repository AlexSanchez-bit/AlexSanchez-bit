# Self-Service Resources

## Introduction

This documentation page provides an overview of self-service resources available for support and assistance. It highlights the tools and platforms that offer information, support, and community engagement for individuals seeking help.

## Red Sobrevivientes Web Platform

The Red Sobrevivientes website is a key resource for survivors in Colombia, offering a platform to share testimonies, connect with allies, and access support resources. The website provides several interactive elements and sections designed to facilitate user engagement and support.

### Key Features

- **Information and Support**: The website offers comprehensive information about the organization's mission and resources available for survivors.
- **Testimony Submission**: Survivors can share their stories through a dedicated testimony submission form.
- **Donation Options**: Users can support the organization through various donation methods, including PayPal and credit/debit cards.

### Interactive Elements

- **Main Navigation Menu**: Provides access to different sections of the website, including the blog and donation pages.
- **Buttons**: Users can confirm their survivor status or request more information through interactive buttons on the homepage.
- **Contact Information**: The website includes contact details such as email and phone numbers for further assistance.

### Access and Navigation

- **Blog and Updates**: The website features a blog section for the latest updates, although some navigation limitations may exist.
- **Allies and Support**: A section dedicated to listing allies and providing additional support information.
