# Emergency Support

## Introduction

This guide provides an overview of critical issue escalation procedures for emergency support. It is designed to help users navigate and utilize the support resources available through the Red de Sobrevivientes Colombia web application. The platform offers a variety of resources, including information, support options, and a community for survivors in Colombia.

## Navigating the Red de Sobrevivientes Web Application

### Main Features

The Red de Sobrevivientes Colombia website provides several key features to assist users:

- **Introduction to the Organization**: The landing page offers an overview of the organization's mission and goals.
- **Call to Action**: Buttons such as "Sí, soy Sobreviviente" and "No, pero quiero información" guide users to relevant resources.
- **Allies Section**: Information about allies and support networks is available.
- **Blog and Latest Entries**: Users can access the latest blog entries for updates and information.
- **Donation Options**: The website provides multiple ways to support the organization through donations.

### Interactive Elements

The website includes several interactive elements to enhance user experience:

- **Main Navigation Menu**: Allows users to explore different sections of the site.
- **Buttons**: Includes options like "Sí, soy Sobreviviente" and "No, pero quiero información" for tailored support.
- **Donation Links/Buttons**: Facilitates easy contributions to support the organization's mission.

## Summary

The Red de Sobrevivientes Colombia web application offers a comprehensive platform for survivors to access support, share their stories, and connect with allies. Key features include a robust navigation system, interactive elements for personalized support, and various pages dedicated to the organization's mission and community engagement. Users can navigate through the site to find the resources they need, contribute to the cause, and participate in the community.

For more information, visit the [Red de Sobrevivientes Colombia website](https://red-sobrevivientes-web.netlify.app).
