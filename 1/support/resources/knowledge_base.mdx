# Knowledge Base

## Introduction

This documentation provides an overview of the knowledge base articles available for support and community resources. It is designed to offer additional learning and reference materials, focusing on searchable knowledge base articles. This page is a high-priority reference for users seeking help and support.

## Navigation and Features

### Red de Sobrevivientes Colombia Web Application

The Red de Sobrevivientes Colombia web application offers a structured navigation system with several key pages and features:

- **Home Page**: Provides an introduction to the organization and includes interactive elements such as call-to-action buttons for survivors and interested parties.
- **Sobre Nosotros**: Offers detailed information about the organization.
- **Blog**: Displays the latest blog entries, although content may sometimes be unavailable.
- **Estadísticas y Mapa**: Presents statistics and maps relevant to the organization's activities.
- **Donation Page**: Features donation options with integrated payment methods like PayPal and credit cards.

For more information, visit the [Red de Sobrevivientes Colombia website](https://red-sobrevivientes-web.netlify.app).

### Interactive Elements

- **Sí, soy Sobreviviente Button**: Opens a form for survivors to share their stories.
- **No, pero quiero información Button**: Redirects users to the "Sobre Nosotros" page.

### Navigation Limitations

Some navigation links do not update the URL hash, which may affect user experience. For example, the "Nuestros Aliados" and "Comparte tu historia" links remain on the base URL.

## Telemática Journal

### About the Journal

The Telemática journal is a scientific-technical publication by the Havana University of Technology "José Antonio Echeverría" (CUJAE). It focuses on telematics and telecommunications, offering peer-reviewed articles aimed at academics, researchers, and students.

- **Open Access**: Provides free access to its content under a Creative Commons Attribution-NonCommercial 4.0 Unported License.
- **Indexed In**: Latindex 2.0, Directory of Open Access Journals (DOAJ), Periodica, and CITMA.

For more details, visit the [Telemática Journal website](https://revistatelematica.cujae.edu.cu/index.php/tele).

### Publication and Content

- **Languages**: Publishes articles in both Spanish and English.
- **Publication Frequency**: Articles are published continuously as they are approved and edited.
- **Open Science Policy**: Encourages open science practices, including preprints and data sharing.
